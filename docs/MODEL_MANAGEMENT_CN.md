# 创作台模型管理

管理员登录并打开画布后，在左侧“画布 / 资产 / 提示词”旁点击“模型管理”，即可原地管理模型，画布和当前项目保持打开。手机上先展开左侧栏。
也可从创作台顶部或 Key 绑定页进入。直接地址：
https://dolorous.asia/studio/admin/models 。普通用户没有入口，后端也拒绝普通用户修改。
即使尚未绑定 Key，管理员仍可从 Key 绑定页或直接地址进入模型管理。

## 添加图片模型

1. 点击“添加模型”。
2. 选择当前账号已绑定的有效 Key，页面自动探测。只有一个可用 Key 时自动选中。
   尚未绑定时，先到创作台的 Key 管理绑定，再回来添加；这里不会自动绑定 Key。
3. 从“选择探测到的图片模型”下拉框选择模型。完整 ID 自动填写，无需手工输入。
   已有模型标记“已配置”，不能重复导入；请在管理列表直接编辑或启用它。
4. 新模型默认启用基础文生图、单张输出、1024×1024 尺寸和 PNG 输出格式。
   上游模型列表不返回完整能力，图片编辑默认关闭。
   根据上游实际支持情况调整文生图、图片编辑、输入/输出图片数量。
   尺寸、画质、输出格式和默认值直接用下拉框修改，无需编辑 JSON。
   确认兼容后，也可在“复制已有模型的参数”中选模板。
5. 点击“保存”，返回创作台选择已绑定的 Key，再从图片模型下拉框选择新模型。
   其他已打开的浏览器标签页需要刷新后读取新名单。

若旧版导入后遇到 `The image job is invalid.`，参见
[输出格式修复与七张生成验收](IMAGE_FORMAT_FIX_CN.md)。当前版本为 `0.1.5-model-sidebar.1`。

探测仅调用主站 `GET /v1/models`，不提交收费生成任务。主站可能返回平台默认名单，
因此“探测到”不等于生成成功，也不证明图片权限、余额、账号调度和所有参数均可用。
探测采用 Key 实际分组的模型名单与白名单；添加模型不授予额外权限。

自动识别当前图片接口支持的 GPT Image、Grok Imagine Image、DALL-E 家族及已经配置的
模型别名。聊天模型、Gemini 图片接口、未知别名不会被凭空当作兼容图片模型导入。
例如 `gpt-image-2.5-flare` 与 `gpt-image-2.5-sunburst` 只有在上游名单返回时才出现。
导入后模型配置仍是全局策略；其他 Key 是否可调用由主站决定，不会自动给其他 Key 授权。

切换 Key 或点击“重新探测”会清除当前选中结果；旧请求不会覆盖新 Key 的结果。
探测失败不会改动现有模型。先检查 Key 是否有效绑定、是否过期、额度及主站分组权限。
若 Key 已被轮换，请在 Key 管理重新绑定。无图片模型时检查主站白名单与模型列表配置。

管理接口为 `GET /canvas-api/v1/admin/model-discovery?api_key_id=数字ID`。
后端重新校验管理员、Key 归属与绑定状态，使用与生成任务相同的加密绑定 Key 查询固定主站地址。
浏览器仅接收模型元数据，不接收 Key 明文；探测禁止跳转、限制响应大小与请求时长。
候选环境允许只读探测，保存仍遵守候选环境的只读限制。

## 在侧栏简单修改参数

1. 打开已有项目，点击左侧“模型管理”，找到模型卡片并点“编辑模型”。
2. 修改“每次最多生成图片数”，例如改为 7；这只是允许上限，实际生成仍要在图片节点选择张数，上游也必须支持。
3. 需要参考图时开启“支持参考图 / 图片编辑”，设置输入图片上限；仅文生图模型不要开启。
4. 在“可用尺寸 / 画质 / 输出格式”选择上游支持的值，右侧选择默认值。可输入自定义选项并按回车确认。
   Grok 等按比例配置的模型会显示宽高比和分辨率。
5. 不指定默认值时选择“由上游决定”。移除某个可用选项时，如果原默认值不再可用，会自动改为列表第一项；清空可选列表则清除对应默认值。按尺寸配置的模型至少保留一个尺寸。
6. “更多选项”可修改背景和蒙版。透明背景不能默认使用 JPEG。“高级能力参数（JSON）”折叠保留，常规修改无需打开。
7. 点击“保存”，当前创作台立即刷新模型配置。点击左侧“画布”继续创作，不需要退出项目。取消则不保存。

未调整的参数会保留；例如旧模型关闭编辑但保留输入数量时，原样保存不会自动改写该数量。
表单只是声明能力，不会让上游自动支持额外尺寸、参考图或更多张数。添加仍使用所选 Key 自动探测。
若出现校验错误，请按提示检查默认值及可用选项；版本冲突时先复制需要保留的改动再重新加载。
这些设置对全部创作台用户生效，仅管理员可修改。

## 编辑、停用和删除

每个模型可编辑、启用/停用或删除；删除不会删除历史项目或图片。
至少保留一个模型，暂时不使用可选择停用。“允许创作台提交图片任务”控制全局开关。
模型名单对所有用户生效；普通用户只能选择，不能修改全局策略。

保存携带读取时的配置版本。若另一个管理员先保存，会提示版本冲突，保留当前编辑内容，
不会自动覆盖。点击“放弃本次编辑并加载最新配置”后再修改。

## 部署与数据

界面调用既有 `GET/PUT /canvas-api/v1/admin/model-policy`，修改由后端记录审计。
候选入口 `/studio-next/admin/models` 使用独立 candidate API，保持只读时不能保存。
本次界面发布不自动增加或删除生产模型，现有模型能力参数完整保留。
发布与回滚使用独立 Canvas 更新流程，不需要更新 Sub2API；发布后照常运行 Key 对账。
如果保存时返回 401，请重新登录；403 表示没有管理员权限；503 `writes_disabled`
表示当前创作台环境只读。不要通过关闭认证或修改生产数据库绕过这些检查。
